# Contributing

Run the game through a static HTTP server as described in the README. Keep changes focused and explain their player impact in pull requests.

The cosmetic catalog is a published policy shared by all players. Do not regenerate random requirements during routine changes. If replacing the policy, update the browser catalog and generated CloudCode together.

Do not commit wallet private keys, seed phrases, access tokens, platform secrets, local dependency folders, or upload archives. Mint addresses and title identifiers are public configuration.

Platform handlers and configuration require publishing through iDosGames. A source commit alone does not deploy them.
