# Roadmap

## Implemented

- Browser game with peer-to-peer rooms and bot Freeplay.
- Five modes, four maps, additional roles, procedural art, and synthesized audio.
- Outcast branding and linked OUTCAST mainnet token.
- Fixed shared wardrobe catalog, server holding checks, and protected selection.
- Ascending wardrobe sorting.
- Mobile joystick and responsive action buttons with safe-area placement.
- iDosGames version 9 published.

## Remaining validation

- Wallet owner confirms authentication, real holdings, equipping, and expiration.
- Feedback from real phones and different network environments.

These are remaining validation tasks, not claims of completed automated testing. No funded wallet transaction was performed during implementation.
